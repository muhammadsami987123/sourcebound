About

A compact, portfolio-quality RAG chatbot

Sourcebound lets you add a website URL or upload a document, then ask questions answered strictly from that source's content — with references back to the exact chunks used. It's built to be small, readable, and honest about what it does, rather than to look impressive with infrastructure it doesn't need.

Technology stack

  • Frontend — HTML5, Tailwind CSS, vanilla JavaScript, Fetch API. No frontend framework, no build step.
  • Backend — Python 3.11+, FastAPI, Uvicorn, Pydantic, the OpenAI Python SDK.
  • RAG — website/document extraction, cleaning, chunking, OpenAI embeddings, NumPy cosine-similarity search, grounded answer generation.
  • Storage — local JSON files plus NumPy embedding files on disk. No database, no Docker, no external vector store.

Design principles

  • Answers are strictly grounded in retrieved chunks — never fabricated, with a clear "not found" response when the source doesn't cover it.
  • Every backend endpoint validates input and returns structured, honest errors instead of raw stack traces.
  • Uploaded filenames and URLs are treated as untrusted input and validated before use.
  • The interface only ever shows real backend data — no invented statistics, sources, or activity.

Known scope & limitations

Sourcebound is intentionally scoped for single-user, local, and portfolio use rather than multi-tenant production deployment:

  • Local JSON/NumPy storage suits a single-user, single-machine, modest-scale deployment — not concurrent multi-writer production use.
  • No authentication or authorization; it's intended for local or personal use.
  • PDF extraction relies on embedded text — scanned or image-only PDFs are not OCR'd.
  • Conversation history is session/local-state based rather than a persisted multi-turn store.
